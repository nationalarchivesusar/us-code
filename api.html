United States Code API

Read-only JSON access to the current published U.S. Code. This is a separate namespace from the existing Criminal Law API and does not alter that API's contract.

Endpoints

Manifest

GET /us-code/data/api/v1/code/manifest.json

API metadata, counts, title indexes, route templates, and compatibility notes.

Title index

GET /us-code/data/api/v1/code/titles/{title}.json

Lists the published sections in one U.S. Code title with citation, heading, URLs, and text verification hash.

Section

GET /us-code/data/api/v1/code/sections/{title}/{section}.json

Returns the current codified section body, source credit, canonical web URL, XML identifier, and SHA-256 text verifier.

Example

To fetch 18 U.S.C. § 1752:

https://nationalarchivesusar.github.io/us-code/data/api/v1/code/sections/18/1752.json 
{
  "schema_version": "1.0",
  "title": "18",
  "section": "1752",
  "citation": "18 U.S.C. § 1752",
  "heading": "…",
  "body": "…",
  "source_credit": "…",
  "web_url": "https://nationalarchivesusar.github.io/us-code/cite/18/1752/",
  "sha256": "…"
}

Contract and scope

  • The API is read-only and represents the current published Code build.
  • Statutory notes are excluded from the compact section payload; source credit is provided separately.
  • Historical comparisons live under the separate section-history research data and are not represented as fabricated intermediate versions.
  • The pre-existing /data/api/v1/criminal-law/ namespace remains independently hardened for Roblox charge-catalog use.
