Controlling Sources

How these sources fit together

PL 36-260

Fixing the District of Columbia Act of 2025

Dissolved the municipal government and adopted the D.C. Criminal Code as federal law in § 10(b), adding a new § 102(11) assigning prosecutions to the U.S. Attorney’s Office for the District of Columbia. Section 10(e) says the adopted laws remain in force until amended or repealed by Congress.

Open Public Law 36-260
PL 37-261

Federal Criminal Code Act of 2025

Re-established a Federal Criminal Code for the District of Columbia and made the attached code enforceable by federal law-enforcement officers across the District. The supplied Act does not expressly repeal the D.C. Criminal Code adopted by PL 36-260, so the reference and booking API expose both sources rather than silently discarding one.

Open Public Law 37-261
PL 39-267

Reform Sentencing Act

Controls non-court-imposed sentencing and caps multi-charge imprisonment at 30 minutes. Its felony/misdemeanor class scheme is published separately because the supplied law does not expressly cross-walk it to the Federal Criminal Code’s A–G offense classes.

Open Public Law 39-267
§

Sentencing data is deliberately not guessed.

Public Law 39-267 uses Class A–E felonies and Class A–C misdemeanors, while the Federal Criminal Code assigns offenses Classes A–G. Because the supplied enactments do not state a crosswalk, the API exposes both schedules and marks the relationship not_expressly_defined rather than inventing one.

Developer Access

Static API for Roblox and other clients

All endpoints are public JSON on GitHub Pages. Roblox should fetch the compact charge catalog once on the server, cache the revision from the manifest, and request full Title 18 text only when an officer opens a section. The compact catalog includes Title 18 charge candidates, Federal Criminal Code offenses, and federalized D.C. Criminal Code offenses. The larger Title 18 full-text search index is intended for the website, not normal in-game startup.

Roblox server exampleLuau
local HttpService = game:GetService("HttpService")
local BASE = "https://nationalarchivesusar.github.io/us-code/data/api/v1/criminal-law/"

local manifest = HttpService:JSONDecode(
    HttpService:GetAsync(BASE .. "manifest.json")
)

local catalog = HttpService:JSONDecode(
    HttpService:GetAsync(BASE .. manifest.endpoints.charges)
)

print(catalog.revision, #catalog.charges)
